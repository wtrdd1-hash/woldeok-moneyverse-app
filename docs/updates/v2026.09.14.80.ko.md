# v2026.09.14.80 — 직업 근무 및 게시판 이미지

## 사용자 변경사항

- Android 앱에서 기존 서버 직업 변경 API를 실제 연결했습니다.
- 개발자, 트레이더, 엔터테이너, 탐정, 광부, 농부, 장인, 공무원 8개 직업을 앱에서 선택할 수 있습니다.
- 서버의 근무 과제 목록을 불러오고 선택한 직업의 과제를 앱에서 완료할 수 있습니다.
- 근무 보상은 앱에서 임의 계산하지 않고 서버 원장 계약을 통해 WLD와 EXP를 지급합니다.
- 게시글 작성 화면에 선택형 이미지 첨부를 추가했습니다.
- 이미지는 인증된 게시판 이미지 업로드 API로 먼저 저장하고, 반환된 저장 키를 게시글에 연결합니다.
- Android 버전을 versionCode 8 / versionName 1.0.7로 올렸습니다.

## API 계약

백엔드에는 직업 변경, 근무 과제, 근무 완료 보상, 게시판 이미지 업로드 및 게시글 이미지 연결 계약이 이미 구현돼 있었습니다. 이번 변경은 빠져 있던 Android 연결을 완성하는 작업입니다. 근무 변경 요청은 세션 + 최신 동의 + CSRF를 그대로 사용하고 WLD 지급 권한은 서버에만 둡니다.

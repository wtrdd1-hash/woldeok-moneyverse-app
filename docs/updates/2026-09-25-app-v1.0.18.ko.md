# Woldeok Moneyverse Android v1.0.18 — 전체 API 및 관리자 앱 확장

- 현재 앱 계약 179개 기능에서 생성한 검색형 전체 기능 허브를 추가했습니다.
- 서버의 관리자 권한 검증을 유지하면서 앱 허용 관리자 기능 11개를 관리자 화면에 포함했습니다.
- 게임·경제·커뮤니티·계정·고객지원 등 자주 쓰는 기능의 기존 전용 화면은 그대로 유지합니다.
- 사용자에게 보이는 앱 정보, 관리자 패널, 활동 행, 네트워크 진단, raw 오류 출력에서 API 경로/주소 노출을 제거했습니다.
- 파괴적 작업 재확인과 path/query/request-body 계약 기반 공통 입력 처리를 추가했습니다.
- debug 빌드는 Test gateway, release 빌드는 Production에 컴파일타임 고정되며 사용자가 서버 주소를 변경할 수 없습니다.
- 179개 고유 기능, 관리자 11개, 일반 회원 168개를 강제하는 회귀 테스트를 추가했습니다.
- GitHub Android CI, 인증된 Test 관리자 검증, 필수 5회 반응형/전체 화면 QA가 끝나기 전에는 릴리스하지 않습니다.

- 재검증 하드닝으로 인증 쿠키를 사용하는 바이너리 미디어 조회, 계약의 4MB 제한을 적용한 PNG/JPEG/WebP raw-byte 업로드, 41개 쓰기 기능의 멱등키 자동 생성을 추가했습니다.
- 좁은 화면에서 제목과 충돌하던 상단 텍스트 버튼을 하나의 더보기 메뉴로 바꿔 전체 기능/관리자 진입의 반응형 안정성을 높였습니다.

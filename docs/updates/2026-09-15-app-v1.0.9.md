# Android App Update — v1.0.9

Date: 2026-09-15

## Changes
- Added Moneyverse server-day/week display in the global app bar.
- Added an animated coin presentation while casino results are being settled by the server.
- Added structured native API telemetry with request IDs, route/status/latency and contract headers; secrets and bodies are not logged.
- Added Android client identity headers for server-side traffic classification.
- Updated work/job compatibility so a missing legacy `featureState` no longer disables career selection by default.
- Bumped Android version to 1.0.9 (versionCode 10).

## Server dependency
The app expects `/app-api/v1/game-clock` and the corrected `/app-api/v1/work/tasks` feature-state contract from the web/backend release v2026.09.15.114.

## Validation
Per operator instruction, this app revision was committed directly to `main` without running the Android test suite in this task.

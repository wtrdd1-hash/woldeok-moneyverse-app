# Woldeok Moneyverse Android v1.0.18 — Full API and administrator app expansion

- Added a searchable all-features hub generated from the current 179-route app contract.
- Included all 11 app-eligible administrator routes inside the administrator experience while preserving server-side administrator verification.
- Kept existing purpose-built screens for common gameplay, economy, community, account, and support flows.
- Removed API route/address details from user-visible app information, administrator panels, activity rows, network diagnostics, and raw error output.
- Added destructive-action confirmation and generic contract-aware input handling for path, query, and request-body fields.
- Debug builds are compile-time pinned to the Test gateway; release builds are compile-time pinned to Production. Users cannot change the service origin.
- Added a regression test requiring 179 unique capabilities, including 11 administrator and 168 member capabilities.
- Release remains gated on GitHub Android CI, authenticated Test administrator verification, and the required five-pass responsive/full-screen QA.

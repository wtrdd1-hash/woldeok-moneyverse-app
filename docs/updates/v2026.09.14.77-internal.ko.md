## 목적

Android 앱의 기존 DTO/호출 형식과 운영 BFF `/app-api/v1` canonical 계약 사이의 불일치를 제거해, 기존 화면을 깨뜨리지 않으면서 서버의 최신 요청/응답 규격을 사용하도록 한다.

## 변경 사항

1. `ApiContractCompatibilityInterceptor` 추가
   - canonical 응답 envelope를 기존 앱 DTO가 읽을 수 있는 형태로 경계 계층에서 정규화한다.
   - 주식, 대출, 사업, 카지노, 시즌, 리더보드, 상점, 게시판, 개인정보, 갤러리, 공지 응답을 포함한다.
2. 쓰기 요청 계약 보정
   - 대출 `amount` → `principalAmount`
   - 카지노 요청 멱등키 자동 보강
   - 사업 정산 요청 멱등키 자동 보강
   - 게시글/댓글 `content` → `body`
   - 개인정보 레거시 query 요청 → canonical JSON body
   - 사업/상점 구매의 레거시 불필요 필드 제거
3. 인증 흐름 보정
   - 일반 로그인은 pre-login 세션만 준비하고, 사용자가 하지 않은 약관 동의를 로그인 과정에서 자동 저장하지 않는다.
   - CSRF 토큰은 응답에서 갱신될 때 앱 네트워크 상태에 반영한다.
4. 모든 계약 접근 경로 보강
   - GET/POST/PUT
   - body 있는 DELETE
   - body 없는 DELETE
   - raw-byte POST
5. 바이너리 안전성
   - JSON이 아닌 이미지/미디어 응답은 compatibility interceptor가 읽거나 재인코딩하지 않는다.
6. CI/회귀 테스트
   - GitHub Actions Android CI 추가
   - MockWebServer 기반 계약 회귀 테스트 추가

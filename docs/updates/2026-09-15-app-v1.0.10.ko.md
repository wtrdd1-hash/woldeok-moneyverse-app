# 앱 v1.0.10 업데이트 — 실시간 API 및 전체 QA

## 변경
- 서버 Socket.IO `market:prices`를 Android에서 구독해 주식 현재가와 시가 대비 등락률을 실시간 갱신합니다.
- 포트폴리오 현재가, 평가금액, 손익률도 동일한 실시간 시세로 갱신합니다.
- 연결이 끊기면 화면의 마지막 REST 응답을 유지하고 Socket.IO 자동 재연결을 수행합니다.
- WebSocket 연결이 불가능한 네트워크에서는 Socket.IO long-polling으로 폴백합니다.
- 앱 버전을 1.0.10(versionCode 11)으로 올렸습니다.

## 보안
- 세션 쿠키는 기존 EncryptedSharedPreferences 기반 CookieJar를 사용하며 Socket.IO에도 같은 서버 세션만 전달합니다.
- Origin은 `https://easy-scraping.com`으로 고정하고 Android client/app-version 헤더를 보냅니다.
- cleartext HTTP 차단, 운영 API 호스트 고정, modern TLS, 민감정보 백업 제외 정책을 유지합니다.

## QA
- 로컬: `testDebugUnitTest`, `assembleDebug`, `lintDebug` 통과.
- GitHub CI: clean/unit test/debug APK/release AAB 검증 후 main 병합.

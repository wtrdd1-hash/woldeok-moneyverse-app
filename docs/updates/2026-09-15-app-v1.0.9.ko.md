# Android 앱 업데이트 — v1.0.9

날짜: 2026-09-15

## 변경사항
- 앱 상단 공통 영역에 머니버스 서버 일/주차 표시를 추가했습니다.
- 카지노 서버 정산을 기다리는 동안 실제 동전이 회전하는 시각 연출을 추가했습니다.
- 요청 ID, API 경로, 상태코드, 지연시간, 계약 버전을 남기는 상세 API 진단 로그를 추가했습니다. 쿠키·CSRF·요청/응답 본문은 기록하지 않습니다.
- 서버에서 Android 앱 트래픽을 분류할 수 있도록 앱 식별 헤더를 추가했습니다.
- 구형 서버가 `featureState`를 누락해도 직업 선택이 자동으로 비활성화되지 않도록 호환성을 개선했습니다.
- Android 버전을 1.0.9(versionCode 10)로 올렸습니다.

## 서버 의존성
앱의 서버시간 표시와 직업 기능 정상화는 웹/백엔드 v2026.09.15.114의 `/app-api/v1/game-clock` 및 `/app-api/v1/work/tasks` 계약 수정과 함께 동작합니다.

## 검증
운영자 지시에 따라 이번 앱 수정은 Android 테스트 실행 없이 `main`에 직접 반영합니다.

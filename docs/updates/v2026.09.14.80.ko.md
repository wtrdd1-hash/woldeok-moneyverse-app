# v2026.09.14.80 — Android API 계약 정합성 수정

## 사용자 변경사항

- 8개 직업 선택을 서버의 현재 직업 변경 API와 연결했습니다.
- 전문 근무 과제를 불러오고 서버가 WLD와 EXP를 지급하도록 근무 완료 기능을 연결했습니다.
- 게시글 작성 시 선택적으로 이미지를 업로드하고 게시글에 첨부할 수 있습니다.
- Android 상점을 Store 2.0으로 맞춰 웹 상점과 같은 카탈로그를 표시합니다.
- 주식 목록, 포트폴리오, 스파크라인, 주문 응답 구조를 실제 서버 계약에 맞췄습니다.
- 사업 카탈로그, 보유 사업, 자기자본, 구매, 정산 요청/응답을 실제 계약에 맞췄습니다.
- 카지노 동전/주사위 요청에 필수 멱등성 키를 추가하고 실제 플레이 영수증을 처리합니다.
- 시즌 이벤트 및 리더보드의 응답 래퍼를 수정했습니다.
- 지갑/은행 쓰기 API는 HTTP 성공 후 서버의 권위 있는 상태를 다시 조회하도록 정리했습니다.
- 홈 공지와 게시판 댓글의 응답 래퍼를 수정했습니다.
- 서버 상태 `operational`을 정상으로 인식해 커뮤니티에서 잘못된 “API 및 서버 준비 중” 표시가 나오지 않게 했습니다.
- Android 버전을 versionCode 8 / versionName 1.0.7로 올렸습니다.

## API 계약

잔액, 가격, 근무 보상, 사업 정산, 카지노 결과, 상점 재고는 계속 서버가 최종 권한을 가집니다. Android는 이제 구형 배열/객체 직접 응답을 가정하지 않고 실제 `/app-api/v1/*` 응답 봉투를 해석합니다. 세션 쿠키, CSRF, 멱등성 요구사항도 서버 정책을 그대로 따릅니다.

## 검증 게이트

최종 커밋에서 Android CI의 `testDebugUnitTest`, `assembleDebug`, `bundleRelease`가 모두 성공한 뒤에만 `main`으로 병합합니다.

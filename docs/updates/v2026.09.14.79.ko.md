# Android 로그아웃 및 운영 API 고정 — v2026.09.14.79

## 요약

- MY 화면에 사용자가 직접 사용할 수 있는 로그아웃 버튼을 추가했습니다.
- 로그아웃 시 서버 로그아웃 API를 호출하고 CookieJar/CSRF/로컬 세션을 정리한 뒤 즉시 로그인 화면으로 이동합니다.
- 일반 사용자에게 노출되던 범용 API 실행 콘솔을 내비게이션과 소스에서 제거했습니다.
- API 환경 프리셋/Mock 전환을 제거하고 Android 앱 API를 `https://easy-scraping.com/` 운영 BFF로 고정했습니다.
- 더 이상 사용하지 않는 Mock 네트워크 인터셉터를 제거했습니다.
- Android 출시 버전을 `versionCode 7`, `versionName 1.0.6`으로 올렸습니다.

## QA 게이트

`main` 병합 전 GitHub Android CI에서 `testDebugUnitTest`, `assembleDebug`, `bundleRelease`를 모두 통과해야 합니다.

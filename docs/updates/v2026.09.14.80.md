# v2026.09.14.80 — Career work and board images

## User-facing changes

- Connect the Android app to the existing server-authoritative career switch API.
- Expose all eight supported careers: developer, trader, entertainer, detective, miner, farmer, artisan, and civil servant.
- Load the server work-task board and allow the selected career to complete eligible tasks.
- Complete work through the server ledger contract so WLD and EXP are awarded by the backend, not calculated on-device.
- Add an optional image picker to board-post creation.
- Upload board images through the authenticated board-image endpoint, then attach the returned storage key to the post.
- Bump Android to versionCode 8 / versionName 1.0.7.

## Contract notes

The backend already owns these contracts. This release fixes missing Android wiring rather than duplicating economy logic in the client. Work mutations remain session + consent + CSRF protected and payouts remain server-authoritative.

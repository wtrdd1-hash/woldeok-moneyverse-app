# v2026.09.14.81 — Daily reward and casino fixes

## User-facing changes

- Daily attendance now reads `/app-api/v1/rewards/availability` before allowing a claim.
- The daily reward button reflects already-claimed / not-yet-eligible state instead of reporting every refusal as a generic failure.
- A successful daily claim refreshes server state immediately.
- Casino stake controls now match the documented server policy of 10–200 WLD per play.
- Added themed casino views for color wheel, treasure, gem and parity slot. These reuse the existing server-authoritative coin/dice engines; the app does not calculate wins locally.
- Android version is now 1.0.8 (versionCode 9).

## Server gate

The casino backend remains protected by the server feature switch and distribution-trial activation gate. The app fixes do not bypass those controls.

# v2026.09.14.77 — Mobile API Contract Compatibility

## English

This update aligns the Android app with the current Woldeok Moneyverse mobile BFF contract under `/app-api/v1` while preserving existing UI behavior.

### Changes

- Added a network-boundary compatibility interceptor for canonical response envelopes and field aliases.
- Corrected canonical request bodies for loans, casino plays, business settlements, board posts/comments, privacy requests, business purchases, shop purchases, and wallet transfers.
- Added automatic idempotency keys where the server contract requires them.
- Preserved binary image/media responses without JSON conversion.
- Added CSRF token refresh handling and explicit JSON/Android request headers.
- Separated sign-in pre-session creation from consent persistence.
- Added generic transport support for GET, POST, PUT, DELETE with/without a body, and raw-byte POST requests.
- Added Android GitHub Actions CI and MockWebServer contract regression tests.

### Contract baseline

- Backend repository: `wtrdd1-hash/Woldeok-Moneyverse-Migration`
- Backend main observed during implementation: `d53d8b0`
- Mobile schema reference: `v2026.09.14.76`

### Release gate

The branch is not eligible for `main` until Android unit tests, debug assembly, safe live BFF smoke checks, and final PR review all pass.

# Woldeok Moneyverse Android v1.0.16 — QA hardening

- Revalidated unit tests, debug build, and Android lint against the current backend contract.
- Restored the executable bit on the Gradle wrapper so CI/local builds can invoke `./gradlew` directly.
- Migrated deprecated OkHttp request-body construction to `ByteArray.toRequestBody`.
- Migrated the community Send icon to the RTL-safe `Icons.AutoMirrored.Filled.Send` API.
- No gameplay/API contract behavior changed in this patch.
- Removed the unreachable legacy `business-types` purchase fallback so business purchases use only the canonical app API route.

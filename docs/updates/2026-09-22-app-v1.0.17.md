# Woldeok Moneyverse Android v1.0.17 — Universal API transport

- Keeps all existing typed BFF integrations unchanged.
- Adds universal GET, POST, PUT, PATCH, and DELETE transport methods using dynamic URLs.
- Supports arbitrary request bodies and per-request headers for new or not-yet-typed BFF routes.
- Uses raw response bodies so JSON and non-JSON endpoints can be integrated without changing the transport layer.
- Retains the production-origin pin, persistent session cookies, CSRF injection, telemetry, and API compatibility interceptor.
- Adds regression coverage that prevents core HTTP verb support from being removed accidentally.
- Bumps Android versionCode to 18 and versionName to 1.0.17.

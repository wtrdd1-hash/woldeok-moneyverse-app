# Android v1.0.13

## 변경 사항
- 커뮤니티 화면에 실시간 로비 채팅을 추가했습니다.
- 회원과 관리자 사이의 영구 저장형 1:1 관리자 문의를 추가했습니다.
- 관리자 화면에 문의함, 답장, 처리 상태 변경을 추가했습니다.
- 성장 레벨과 경험치를 UI 하드코딩 값이 아니라 서버의 work/profile API 기준으로 표시합니다.
- 문의 API는 모두 공개 모바일 BFF(`/app-api/v1`)를 사용하며 세션 쿠키와 CSRF 보호를 유지합니다.

## 검증
- `testDebugUnitTest` 통과.
- `lintDebug` 통과.
- `assembleDebug` 통과.
- `bundleRelease` 통과 및 `app-release.aab` 생성 확인.

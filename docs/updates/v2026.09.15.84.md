# v2026.09.15.84 — Economy usability and server-policy synchronization

## Summary

- HTTP failures shown to users now expose the status number only instead of server error bodies or internal detail text.
- Added API-backed shop search by product name, description, and category.
- Already-owned business types are removed from the purchase list, with both server-side authority and an app-side safety filter.
- Added full-amount controls to cash transfer, bank deposit/withdrawal, loan repayment, stock maximum buy, and stock full sell flows.
- The work screen reads the server's administrator-controlled `featureState` and disables career/work actions when restricted.

## Server dependency

This release pairs with Moneyverse Migration `v2026.09.15.96`, which provides shop search, authoritative business filtering, work feature-switch enforcement, and HTTPS hardening.

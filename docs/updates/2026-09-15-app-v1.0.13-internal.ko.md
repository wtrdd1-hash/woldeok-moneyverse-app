# 내부 업데이트 Android v1.0.13

## 작업 순서
1. 기존 v1.0.13 작업 브랜치를 최신 `main` 기준으로 확인했습니다.
2. 실시간 로비 채팅과 관리자 문의 탭을 커뮤니티 화면에 연결했습니다.
3. 지원 DTO/API/ViewModel을 추가하고 관리자 답장·상태 변경을 모바일 BFF에 연결했습니다.
4. 관리자 화면을 실제 관리자 세션/API 기반 운영 화면으로 변경했습니다.
5. 서버에서 내려오는 직업 레벨·경험치를 사용하도록 성장 표시 하드코딩을 제거했습니다.
6. 모바일 계약 테스트에 support 경로를 고정했습니다.

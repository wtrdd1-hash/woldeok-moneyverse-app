# v2026.09.15.82 — 주식 시장 및 사업 구매 안정화

## 요약

모바일 경제 화면에서 주식 목록이 표시되지 않던 응답 파싱 충돌을 수정하고, 주식 주문 및 사업 구매 쓰기 요청의 인증 안정성을 보강했습니다.

## 변경 사항

- 주식 응답을 정규 `{ "stocks": [...] }` 봉투형과 앱 호환 인터셉터가 변환한 `[...]` 배열형 모두 처리하도록 수정했습니다.
- 주식 등락률을 런타임 어댑터에서 소수점 둘째 자리까지 반올림합니다.
- 주식 상세 화면에서 `▲/▼`, 퍼센트, `이익/손해` 문구를 크게 표시해 등락을 명확히 구분합니다.
- 주식 주문 또는 사업 구매가 HTTP 403을 반환하면 viewer/CSRF 상태를 갱신한 뒤 동일 멱등키로 1회만 재시도합니다.
- 사업 구매 정규 API `POST /app-api/v1/businesses/catalog/{id}/purchases`를 유지합니다.

## 원인

서버는 주식 목록을 객체 봉투로 반환하지만 앱 호환 인터셉터가 기존 typed API를 위해 배열로 변환합니다. 실제 경제 화면이 사용하는 런타임 저장소가 이 변환된 배열을 다시 객체로 간주해 `stocks`를 꺼내려 하면서 JSON 형태 예외가 발생했고, 결과적으로 주식 목록이 비어 보였습니다.

# v2026.09.15.86 — 근무 일일 한도 UI 정합성 수정

## 요약
Android 앱이 백엔드 `v2026.09.15.102`에서 복구된 authoritative 근무 일일 한도 값을 직접 사용하도록 수정했습니다.

## 변경 사항
- 근무 과제 API의 `dailyLimit`/`takenToday` 및 `daily_limit`/`taken_today`를 모두 파싱합니다.
- 각 과제에 오늘 수행 횟수, 일일 한도, 남은 횟수를 표시합니다.
- 일일 한도를 모두 사용한 과제는 앱에서 완료 버튼을 비활성화합니다.
- 서버에서 완료 요청이 거부된 경우 과제 목록을 다시 읽어 동시 요청/서버 측 최신 quota 상태를 반영합니다.
- 관리자 `featureState` 스위치와 사용자별 과제 quota를 별도로 취급합니다.

## 호환성
- 백엔드 계약: `GET /app-api/v1/work/tasks`.
- 일일 한도의 최종 권한은 계속 서버/DB에 있으며 앱의 선제 차단은 UX 보조입니다.
- 기존 숫자 중심 HTTP 상태 표시 정책을 유지합니다.

## 작업 단계
- `v86-01`: 앱 `main`과 백엔드 quota 계약 재확인.
- `v86-02`: `WorkTaskUi`에 quota 필드 파싱 추가.
- `v86-03`: 사용량/남은 횟수 표시 및 소진 과제 버튼 차단.
- `v86-04`: 완료 요청 거부 시 작업 목록 재조회.
- `v86-05`: 코드/CI 재검토 후 main 통합.

# v2026.09.15.85 — 갤러리 이미지 및 HTTP 숫자 오류 정리

## 변경사항
- 갤러리 API가 내려주는 `/media/...` 상대 이미지 주소를 앱의 고정 운영 주소 `https://easy-scraping.com/` 기준 절대 URL로 변환합니다.
- 갤러리 이미지 주소가 실수로 `http://`로 오면 Coil에 전달하기 전에 `https://`로 정규화합니다.
- 갤러리 조회 HTTP 실패는 사용자에게 숫자 상태코드만 표시합니다.
- 출석 보상 조회/수령 HTTP 실패도 숫자 상태코드만 표시합니다.
- v2026.09.15.84의 상점 검색, 이미 보유한 사업 구매목록 제외, 전액/MAX 버튼, 직업 제한 연동, HTTP 오류 본문 미노출 변경을 함께 포함합니다.

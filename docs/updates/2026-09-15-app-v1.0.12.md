# App v1.0.12 — Exact full WLD display

- Version: 1.0.12 (versionCode 13)
- Branch: `fix/money-display-v1.0.12`
- All dynamic WLD displays now use the shared exact formatter.
- Values are grouped every three digits without compact units or floating-point conversion.
- Example: `10773 WLD` -> `10,773 WLD`.
- Wallet, bank, work rewards/quotas, casino limits/stakes, stock details, and reward messages use the same rule.
- Exact arbitrary-length decimal strings remain intact for the v1.0.11+ API contract.

# v2026.09.15.86 — Work Daily Quota App Alignment

## Summary
The Android app now honors the backend work quota contract restored in backend release `v2026.09.15.102`.

## Changes
- Parse `dailyLimit` / `daily_limit` from work task payloads.
- Parse `takenToday` / `taken_today` from work task payloads.
- Show today's usage and remaining attempts per work task.
- Disable task completion when the server-reported daily quota is exhausted.
- Add a client-side quota guard before sending a completion request.
- Reload work task state after server rejection so the app immediately reflects authoritative server quota.
- Preserve numeric-only HTTP status presentation for API failures.

## Compatibility
A `dailyLimit` value of `0` remains treated as unlimited for compatibility with legacy payloads. The backend is authoritative for quota enforcement.

## Validation
- Added unit coverage for remaining quota, exhausted quota, and legacy unlimited behavior.
- Android CI is the merge gate for this release.

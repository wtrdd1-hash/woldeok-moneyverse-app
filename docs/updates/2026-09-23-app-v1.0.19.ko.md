# Woldeok Moneyverse Android v1.0.19 — 전체 App API 기능 동등성

- 공개 모바일 계약 v2026.09.22.359의 179개 endpoint 전체 레지스트리를 Android에 추가했습니다.
- 백엔드 v2026.09.22.360에서 활성화된 개인채팅 11개 작업을 추가해 총 190개 앱 실행 경로를 제공합니다.
- App Gateway 33개 그룹을 모두 확인할 수 있는 앱 내 **전체 기능** 화면을 추가했습니다.
- GET/POST/PUT/DELETE는 기존 보안 BFF transport, 영속 세션 쿠키, CSRF, telemetry, compatibility 처리를 그대로 사용합니다.
- 경로 파라미터를 앱에서 입력할 수 있고 변경 요청 JSON 템플릿과 멱등 UUID 자동생성을 지원합니다.
- 저금통, 제작, P2P 마켓 명령의 실제 DTO 기반 입력 템플릿을 보강했습니다.
- 계약 감사 결과 공식 모바일 endpoint 179/179가 Android에 존재하며 누락은 0개입니다.
- 운영 비파괴 GET 79개 전수 스모크 결과 200=15, 로그인 필요 401=64, 404=0입니다.
- 단위테스트, Android Lint, Debug APK 빌드, diff 검사가 모두 통과했습니다.
- 버전: versionCode 20 / versionName 1.0.19.

## 격리 테스트 / 실제 에뮬레이터 QA 후속
- Debug 빌드는 컴파일 시 `https://test.easy-scraping.com/`에 고정하고 Release 빌드는 `https://easy-scraping.com/`에 고정했습니다.
- API origin은 사용자가 변경할 수 없으며 HTTPS/호스트 검증으로 그 외 목적지는 계속 차단합니다.
- Android 36 Google APIs x86_64 에뮬레이터(`wdmv_api36`)를 만들고 v1.0.19 Debug APK 실제 설치에 성공했습니다.
- MainActivity가 RESUMED 상태로 진입했고 Android UI hierarchy에서 로그인/회원가입 네이티브 UI를 확인했습니다.
- 실제 회원가입 제출은 격리 Test 백엔드까지 도달했으며 HTTP 503을 반환했습니다. 원인은 테스트 SMTP 미설정 + production-like 백엔드 모드 조합으로 확인했습니다.
- 백엔드 수정은 v2026.09.23.387로 진행하며 exact-SHA Test 배포/E2E 통과 전 앱 PR을 병합하지 않습니다.

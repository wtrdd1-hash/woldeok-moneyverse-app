## 역사/실행 참조

- `APP_SPEC_AND_USER_GUIDE.ko.md`는 **역사 명세 스냅샷**(v2026.09.22.343)이다. 카지노, 런타임, DB 등 현재 웹 권위와 달라졌을 수 있는 과거 가정을 포함한다.
- 저장소 루트 `implementation_plan.md`는 실행 계획/누적 구현 이력이며 그 자체로 제품 권위가 아니다.
- `docs/api/`는 통합 스냅샷이다. 최신 생성/runtime 계약 또는 웹 권위 기획과 충돌하면 웹 권위와 exact runtime 증거를 따른다.

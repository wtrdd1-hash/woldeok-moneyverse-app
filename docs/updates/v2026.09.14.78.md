# Android Play release hardening — v2026.09.14.78

- Run Android CI on `main` as well as development branches.
- Build `bundleRelease` in CI and retain the AAB as an artifact.
- Add a manual signed Play bundle workflow that reads the upload keystore only from GitHub Actions secrets.
- Keep signing material out of Git and fail closed when required signing secrets are absent.
- Required secrets: `ANDROID_UPLOAD_KEYSTORE_BASE64`, `ANDROID_UPLOAD_STORE_PASSWORD`, `ANDROID_UPLOAD_KEY_ALIAS`, `ANDROID_UPLOAD_KEY_PASSWORD`.

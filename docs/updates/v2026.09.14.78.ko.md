# Android Play 릴리스 보강 — v2026.09.14.78

- 개발 브랜치뿐 아니라 `main`에서도 Android CI를 실행합니다.
- CI에서 `bundleRelease`를 빌드하고 AAB를 아티팩트로 보관합니다.
- 업로드 키스토어를 GitHub Actions Secret에서만 읽는 수동 서명 Play 번들 워크플로를 추가합니다.
- 서명 자료는 Git에 넣지 않으며 필수 Secret이 없으면 실패하도록 구성합니다.
- 필수 Secret: `ANDROID_UPLOAD_KEYSTORE_BASE64`, `ANDROID_UPLOAD_STORE_PASSWORD`, `ANDROID_UPLOAD_KEY_ALIAS`, `ANDROID_UPLOAD_KEY_PASSWORD`.

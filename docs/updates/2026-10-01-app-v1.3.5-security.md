# Android App v1.3.5 — Signing Hygiene

**English canonical** | [한국어](2026-10-01-app-v1.3.5-security.ko.md)

Status: IMPLEMENTED / CI_REQUIRED

- Version bumped to 1.3.5 (versionCode 36).
- Removed public release-signing password fallbacks.
- Release signing now requires the keystore path, store password, key alias, and key password from environment variables.
- Debug builds no longer use release signing configuration.
- General pull-request CI runs unit tests and debug assembly only.
- Signed release bundles remain isolated in the manual Play workflow backed by GitHub Secrets.
- Internal update records were removed from the public tracked tree and are ignored going forward.
- Private operations-gateway details were removed from the public historical app guide.

Local static security checks and git diff checks pass. This Debian host has no Android SDK, so Gradle build verification must come from pull-request CI. No Play/Production release is claimed.

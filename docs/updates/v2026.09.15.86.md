# v2026.09.15.86 — Work quota UI alignment

## Summary
The Android app now consumes the backend-authoritative work quota fields restored by backend release `v2026.09.15.102`.

## Changes
- Parse both `dailyLimit`/`takenToday` and `daily_limit`/`taken_today` from the work-task API.
- Show today's usage, configured daily limit, and remaining completions on each work task.
- Disable a task's completion button after its daily quota is exhausted.
- Re-check the task board after a server-side completion failure so concurrent/server-side quota state is refreshed.
- Keep the administrator `featureState` switch separate from per-task member quota.

## Compatibility
- Backend contract: `GET /app-api/v1/work/tasks`.
- Quota remains authoritative on the server/database; the Android check is UX only and cannot replace server enforcement.
- Existing numeric-only HTTP status presentation is preserved.

## Version stages
- `v86-01`: re-check app `main` and backend quota contract.
- `v86-02`: parse quota fields into `WorkTaskUi`.
- `v86-03`: display usage/remaining quota and disable exhausted tasks.
- `v86-04`: refresh task board after rejected completion.
- `v86-05`: code/CI review and main integration.

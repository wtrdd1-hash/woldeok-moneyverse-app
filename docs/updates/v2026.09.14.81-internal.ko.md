# 내부 업데이트 v2026.09.14.81

## 원인

1. 일일 출석 UI가 `GET /app-api/v1/rewards/availability`를 사용하지 않고 수령 POST만 호출해 이미 수령/대기 상태도 일반 실패처럼 보였다.
2. Android 카지노 슬라이더가 100,000~5,000,000 WLD로 하드코딩돼 서버 정책 10~200 WLD와 불일치했다.
3. 서버 카지노는 `feature_switch_state('casino')`가 enabled가 아니면 플레이를 거절하도록 설계돼 있다.
4. 서버 활성화는 100만 회 이상 통과 분포시험을 요구하는 DB 트리거로 보호된다.

## 변경

- 출석 availability 조회 전용 ViewModel 추가, 수령 후 상태 재조회.
- 카지노 1회 배팅 10~200 WLD로 정합화.
- 컬러 휠/보물/젬/홀짝 슬롯 UI 추가. 신규 확률 로직을 앱에 만들지 않고 검증된 코인/주사위 서버 결과를 테마 표시로 재사용.
- 앱 1.0.8 / versionCode 9.

- Android CI `testDebugUnitTest assembleDebug bundleRelease` 성공 전 main 병합 금지.
- 카지노 서버 스위치는 테스트 서버의 qualifying distribution trial 및 기존 보호장치 확인 전 운영 활성화 금지.

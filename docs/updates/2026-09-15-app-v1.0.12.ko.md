# 앱 v1.0.12 — WLD 전체 금액 표시 통일

- 버전: 1.0.12 (versionCode 13)
- 브랜치: `fix/money-display-v1.0.12`
- 앱의 동적 WLD 표시를 공통 정확 포맷터로 통일했습니다.
- 만/억/k/M 축약 없이 3자리마다 쉼표를 표시합니다.
- 예: `10773 WLD` -> `10,773 WLD`.
- 지갑, 은행, 작업 보상/한도, 카지노 한도/배팅, 주식 상세, 보상 메시지에 동일 규칙을 적용합니다.
- v1.0.11 이상 API의 임의 길이 금액 문자열도 정밀도 손실 없이 유지합니다.

# App v1.0.10 — realtime API and full QA

## Changes
- Android now subscribes to the server Socket.IO `market:prices` feed for live stock quotes.
- Portfolio value and P/L are recomputed from the same pushed prices.
- The last REST snapshot remains visible while Socket.IO reconnects, with long-polling fallback.
- Version: 1.0.10 (versionCode 11).

## Security
- Reuses the encrypted session CookieJar for the first-party socket only.
- Pins the Origin to `https://easy-scraping.com` and sends native client/version identity headers.
- Existing HTTPS-only, production-host pinning, modern TLS and backup-exclusion controls remain enforced.

## QA gate
- Local unit tests, debug assemble and Android lint must pass.
- GitHub CI must additionally build the release AAB before merge to main.

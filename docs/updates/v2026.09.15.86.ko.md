# v2026.09.15.86 — 직업 일일 한도 앱 정합성 수정

## 요약
Android 앱이 백엔드 `v2026.09.15.102`에서 복구한 직업/작업 일일 수행 한도 계약을 그대로 반영하도록 수정했습니다.

## 변경 사항
- 작업 응답의 `dailyLimit` / `daily_limit`를 읽습니다.
- 작업 응답의 `takenToday` / `taken_today`를 읽습니다.
- 각 작업에 오늘 수행량과 남은 횟수를 표시합니다.
- 서버가 알려준 일일 한도를 모두 사용하면 완료 버튼을 비활성화합니다.
- 완료 API 요청 전 앱에서도 한도 소진 여부를 확인합니다.
- 서버가 요청을 거부하면 작업 목록을 다시 불러와 authoritative quota를 즉시 동기화합니다.
- API 오류는 기존 정책대로 HTTP 상태 코드 중심 표시를 유지합니다.

## 호환성
레거시 응답 호환을 위해 `dailyLimit = 0`은 무제한으로 처리합니다. 실제 한도 판정과 보상 차단은 백엔드가 최종 권한을 가집니다.

## 검증
- 남은 횟수, 한도 소진, 레거시 무제한 동작에 대한 단위 테스트를 추가했습니다.
- 이번 버전은 Android CI 성공을 병합 게이트로 사용합니다.

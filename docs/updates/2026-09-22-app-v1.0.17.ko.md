# Woldeok Moneyverse Android v1.0.17 — 범용 API transport

- 기존 typed BFF 연동은 그대로 유지합니다.
- 동적 URL 기반 범용 GET, POST, PUT, PATCH, DELETE 호출 경로를 추가했습니다.
- 아직 typed Retrofit 함수가 없는 신규/기존 BFF API도 임의 RequestBody와 요청별 헤더로 바로 연결할 수 있습니다.
- 범용 응답을 raw ResponseBody로 받아 JSON 이외 응답도 네트워크 계층 변경 없이 처리할 수 있습니다.
- 운영 origin 고정, 영속 세션 쿠키, CSRF 주입, telemetry, API 호환성 interceptor는 그대로 유지합니다.
- 핵심 HTTP verb 지원이 앱 수정 과정에서 제거되지 않도록 계약 회귀 테스트를 추가했습니다.
- Android versionCode 18, versionName 1.0.17로 갱신했습니다.

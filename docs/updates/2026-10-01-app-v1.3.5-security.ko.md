# Android 앱 v1.3.5 — Signing 보안 정리

[English canonical](2026-10-01-app-v1.3.5-security.md) | **한국어**

상태: IMPLEMENTED / CI_REQUIRED

- 버전을 1.3.5(versionCode 36)로 올렸다.
- 공개 release-signing 비밀번호 fallback을 제거했다.
- release signing은 키스토어 경로, 스토어 암호, 키 별칭, 키 암호를 모두 환경변수로 요구한다.
- debug 빌드는 더 이상 release signing 설정을 사용하지 않는다.
- 일반 PR CI는 unit test와 debug assemble만 수행한다.
- signed release bundle은 GitHub Secrets를 사용하는 수동 Play workflow에만 남긴다.
- 내부 업데이트 기록을 공개 추적 트리에서 제거하고 재추적을 방지한다.
- 공개 역사 앱 가이드에서 비공개 운영 게이트웨이 세부를 제거했다.

로컬 static security check와 git diff check는 통과했다. Debian 호스트에는 Android SDK가 없어 Gradle 빌드 검증은 PR CI에서 수행해야 한다. Play/Production release를 주장하지 않는다.
